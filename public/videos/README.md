# Video assets

Empty by design — no brand films ship with this concept.

Drop your files here:

    hero.mp4              hero.webm
    clinic-experience.mp4 clinic-experience.webm
    medical-technology.mp4 medical-technology.webm

Then uncomment the matching `mp4` / `webm` lines in
`src/components/video/VideoBlock.tsx`.

Until then each slot shows its poster image from `public/images/`, which is a
finished visual state rather than a placeholder.

Generation prompts are in the root README, section 3.
